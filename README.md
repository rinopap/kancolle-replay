## Fork notes (rinopap)

- KanColle (艦隊これくしょん -艦これ-) images, names and data belong to their respective rights holders. This project is not affiliated with them.
- Simulation results are estimates and do not guarantee actual in-game results.
- The file manager keeps files in the browser (IndexedDB) only; nothing is uploaded. The "create shared link" feature of the simulator sends the data to external services (kcrdb, tinyurl).
- `js/lib/lzma_worker-min.js` is lzma-js 2.3.2 (MIT, see `js/lib/LICENSE-lzma.txt`).
